# Cleber Pavin | Tecnologia & Desenvolvimento

Site profissional e portfólio de Cleber Pavin, com apresentação de projetos, serviços, segmentos atendidos e solicitação de orçamento pelo WhatsApp.

## Principais páginas

- Home e projetos em destaque
- Portfólio com cases detalhados
- Serviços e faixas de investimento
- Segmentos atendidos
- Sobre
- Formulário de orçamento integrado ao WhatsApp

## Stack

- React
- TypeScript
- Vite
- React Router
- CSS

## Execução local

```bash
npm install
npm run dev
```

Validações disponíveis:

```bash
npm run typecheck
npm run lint
npm run build
```
